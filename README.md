# 🚀 Autolysis-2.0

Autolysis-2.0 is an intelligent data analysis and automation system designed to ingest **tabular and image datasets**, generate **deep insights**, build **interactive dashboards**, and apply **machine learning techniques** to extract value from data.

The system is currently focused on **tabular data processing**, with image-based analysis planned for future development.

---

## 🧠 Project Vision

The goal of Autolysis is to create an end-to-end autonomous data intelligence system that can:

- Ingest raw datasets (CSV, images, etc.)
- Automatically classify and understand data structure
- Generate statistical + ML-driven insights
- Build visual dashboards dynamically
- Support multiple LLM providers for reasoning and analysis
- Expand into multimodal analysis (tabular + images)
